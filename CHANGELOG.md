## Next Version (Unreleased)

FEATURES:

- Add the `include_inactive_machines` option, which adds some or all machines
  that have not been created to the inventory generated by the `ansible_auto`
  provisioner.  Disabled by default.
  ([#1](https://github.com/tomeon/vagrant-ansible_auto/issues/1))

IMPROVEMENTS:

- Update development dependencies so that the unit tests and RuboCop run on
  current Ruby releases: test against Vagrant 2.4.9 and the latest
  vagrant-spec, and move to RuboCop 1.x, SimpleCov 1.x, and newer versions of
  Rake and RSpec.  Development now requires Ruby 3.2 or later, the minimum for
  SimpleCov 1.x.
- Replace Travis CI with GitHub Actions.  The test suite (RuboCop, unit tests,
  and vagrant-spec acceptance tests) runs against the Ruby shipped by Ubuntu
  24.04 LTS, Ubuntu 26.04 LTS, the latest Ubuntu interim release, Debian stable,
  Debian testing, and AlmaLinux 10.  Coverage is uploaded to Coveralls by the
  Coveralls GitHub Action, replacing the unmaintained `coveralls` gem.
- Work around vagrant-spec dropping keyword arguments under Ruby 3, which made
  every acceptance test fail.

BUG FIXES:

## 0.2.4 (August 07, 2020)

FEATURES:

IMPROVEMENTS:

BUG FIXES:

- `s/chmod/chown/` in
  `VagrantPlugins::AnsibleAuto::Provisioner#create_and_chown_remote_folder`.

## 0.2.3 (August 07, 2020)

**NOTE** yanked due to use of `chmod` rather than `chown` in
`VagrantPlugins::AnsibleAuto::Provisioner#create_and_chown_remote_folder`.

IMPROVEMENTS:

- Update development dependencies, including updating to the current stable
  Vagrant release (2.2.9).

BUG FIXES:

- Disable Vagrant plugin loading and plugin system initialization when running
  unit tests; this isolates our tests from the user's existing Vagrant
  environment (e.g. the stuff undef `~/.vagrant.d`) and help avert breakage due
  to problems with globally-installed Vagrant plugins.
- Add missing `require "simplecov"` to [`spec/spec_helper.rb`], correcting a
  fatal `NameError` referring to `SimpleCov`.
